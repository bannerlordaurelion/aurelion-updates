# Bannerlord Aurelion — launcher updates

This repository is read automatically by the Bannerlord Aurelion launcher.

- `manifest.json` — server info, news, guide, Discord link and the list of server mods (with SHA-256 for every file)
- `files/` — the mod files the launcher downloads

Players do not need to open this page. Download the launcher from the official Bannerlord Aurelion website.
